# ShardFlow 前端布局重构设计

> 版本: 1.0 | 日期: 2026-05-22 | 参考: `docs/frontend.json`

---

## 一、设计目标

将前端从"登录墙"模式改造为"先体验后登录"模式，布局参考 Kimi 风格，视觉 token 严格遵循 `docs/frontend.json`。

**核心原则：**
- 打开页面直接看到对话区，无需登录
- 未登录**仅可查看界面**，无法使用任何功能（输入框置灰，点击弹出登录弹窗）
- 登录/注册用弹窗，不跳页
- 侧栏默认展开，可手动折叠

---

## 二、布局结构

```
┌──────────────────┬────────────────────────────────────┐
│  侧栏 (280px)    │         主区域 (flex: 1)            │
│  背景: #16162a   │  背景: #f7f7f8                      │
│                  │                                    │
│  [ShardFlow]     │         对话区 (max 720px 居中)     │
│  Logo + 名称     │                                    │
│                  │                                    │
│  ──────────────  │                                    │
│  工具            │   ┌──────────────────────────┐     │
│  ├ Skill  🔒/✅  │   │  用户消息气泡 (蓝色右侧)   │     │
│  ├ MCP    🔒/✅  │   └──────────────────────────┘     │
│  ──────────────  │                                    │
│  历史对话        │   AI 回复 (无背景，直接 Markdown)   │
│  ├ 对话1         │                                    │
│  ├ 对话2         │                                    │
│  ──────────────  │   ┌──────────────────────────┐     │
│  [头像] [昵称]   │   │ 输入你的问题...      [发送]│     │
│  或 [登录]       │   └──────────────────────────┘     │
│                  │   Skill 市场 · 接入 MCP             │
└──────────────────┴────────────────────────────────────┘
```

### 2.1 侧栏详情

| 区域 | 内容 | 未登录 | 已登录 |
|------|------|--------|--------|
| 顶部 | ShardFlow Logo | 显示 | 显示 |
| 工具区 | Skill 按钮、MCP 按钮 | 置灰 + 🔒，hover 提示"登录后可用" | 可点击，打开弹窗 |
| 历史区 | 对话历史列表 | 不显示（空状态引导"登录后查看历史"） | 显示最近对话 |
| 底部 | 用户头像 + 昵称 | 显示「登录」按钮 | 头像 + 昵称，点击展开设置/退出 |

- 侧栏宽度：280px（`layout.sidebar_width`）
- 折叠态：仅图标，宽度 64px
- 折叠按钮：汉堡图标，在侧栏顶部 Logo 旁
- 移动端 (<768px)：侧栏变为底部 Drawer，从左侧滑出

### 2.2 对话区详情

- 最大宽度：720px 居中（`layout.chat_max_width`）
- 欢迎态（无消息时）：居中标题「有什么我可以帮你的？」+ 副标题
- 消息列表：用户蓝色气泡右对齐，AI Markdown 左对齐无背景

### 2.3 输入区（未登录态）

- 圆角：16px（`components.input.radius`）
- 底部居中，最大宽度 720px
- 输入框**完全置灰**（`disabled` 态），placeholder："登录后开始对话"
- 点击输入框或发送按钮 → 弹出登录弹窗
- 输入框下方显示 Skill 市场 / 接入 MCP 文字按钮（同样点击弹出登录弹窗）

### 2.4 输入区（已登录态）

- 输入框恢复正常，placeholder："输入你的问题..."
- 发送按钮蓝色可点击
- 输入框下方 Skill 市场 / 接入 MCP 按钮可用

## 三、登录/注册弹窗

### 3.1 弹窗规格

| 属性 | 值 |
|------|-----|
| 最大宽度 | 400px (`layout.modal_max_width`) |
| 圆角 | 16px (`components.modal.radius`) |
| 阴影 | `0 24px 80px rgba(0,0,0,0.16)` |
| 内边距 | 32px |
| 遮罩 | `rgba(0,0,0,0.45)` |

### 3.2 内容

- 顶部 ShardFlow Logo
- Tab 切换：[登录] [注册]
- 登录：用户名 + 密码 + 登录按钮
- 注册：用户名 + 密码 + 确认密码 + 注册按钮
- 第三方登录预留位置
- 关闭按钮 (✕) 右上角

### 3.3 触发场景

- 侧栏底部「登录」按钮
- 点击置灰的输入框或发送按钮
- 点击置灰的 Skill/MCP 按钮
- 访问需登录页面（/history 等）时弹出

---

## 四、Skill 弹窗

- 弹出 Modal，列出可用 Skill
- 每个 Skill 显示名称 + 描述 + 启用开关
- 搜索框支持过滤
- 点击启用后 Skill 图标在侧栏亮起

## 五、MCP 弹窗

- 弹出 Modal，工具列表表格
- 显示名称/描述/状态/延迟
- 「注册新工具」按钮 → 表单弹窗
- 与 `/mcp-tools` 页面共享 API

## 六、路由设计

| 路径 | 页面 | 权限 |
|------|------|------|
| `/` | 对话主页 | 所有人（未登录仅查看） |
| `/history` | 会话历史 | 需登录 |
| `/mcp-tools` | MCP 工具管理 | 需登录 |
| `/profile` | 用户画像 | 需登录 |
| `/login` | 登录页（保留） | 所有人 |
| `*` | 404 | 所有人 |

`/` 为默认路由，移除强制登录重定向。所有需登录页面由路由守卫处理，未登录跳转 `/` 并弹出登录弹窗。

## 七、视觉 Token 引用

所有颜色、字体、间距、圆角、阴影引用 `docs/frontend.json`：

| 用途 | Token 路径 |
|------|-----------|
| 侧栏背景 | `color.sidebar.bg` = `#16162a` |
| 主强调色 | `color.accent.primary` = `#4e7dff` |
| 用户气泡 | `color.chat.user_bubble` = `#4e7dff` |
| 输入框圆角 | `components.input.radius` = `16px` |
| 弹窗圆角 | `components.modal.radius` = `16px` |
| 对话区最大宽度 | `layout.chat_max_width` = `720px` |
| 字体 | `typography.family` |

## 八、未登录行为总结

| 操作 | 未登录 | 已登录 |
|------|--------|--------|
| 查看对话界面 | ✅ | ✅ |
| 发送消息 | ❌ 输入框置灰 | ✅ |
| 使用 Skill | ❌ 锁定 | ✅ |
| 使用 MCP | ❌ 锁定 | ✅ |
| 查看历史对话 | ❌ 不展示 | ✅ |
| 编辑画像 | ❌ 需登录 | ✅ |
| 访问 /history 等页面 | ❌ 弹出登录弹窗 | ✅ |

- 未登录态不存储任何 localStorage 限额
- 所有功能入口点击 → 弹出登录弹窗
- 登录成功后所有锁定状态即时解除

---

## 九、非目标

- 不做 i18n 国际化
- 不做暗黑模式切换（当前仅浅色主题）
- 不做语音输入
- 不做 PWA/离线模式
